## 1. `_meta.js` — `type: 'menu'` requires `items`

**Error:** `✖ Invalid input`

**Root cause:** `content/_meta.js` had:
```js
philosophy: { title: 'Philosophy', type: 'menu' }
```

Nextra's `menuSchema` (defined in `nextra/dist/server/schemas.js`) uses `z.strictObject` and requires an `items` field:
```js
const menuSchema = z.strictObject({
  type: z.literal("menu"),
  title,
  items: z.record(z.string(), menuItemSchema).transform(...),
  display: z.enum(["normal", "hidden"]).optional()
});
```

Since `items` was missing, `metaSchema.safeParse()` failed for this entry and `normalizePageMap()` threw `z.prettifyError(error)` during page map generation. This error surfaced as a generic `✖ Invalid input` from Zod's union validation.

**Fix:** Changed to a plain string:
```js
philosophy: 'Philosophy'
```

See https://nextra.site/docs/file-conventions/meta-file#menus for Nextra's `_meta.js` menu syntax.
